# 预览版验证记录

版本：1.1.0-preview.1；日期：2026-11-16。

## 已完成的隔离测试

- 29项Python自动测试（其中一项运行8个前端恢复用例）：管理员权限与请求来源、限时单次授权、并发兑换、防伪造凭证、同设备续装、越权代理与端口拒绝、停用后重连拒绝、迟到健康检查、防止错误回收端口，保留原代理认证与请求路径，以及邀请状态与隐私边界、链接片段授权和静态演示导出。
- 使用真实FRP0.70.1、OIDC与Nginx连接两个模拟Jira源，验证独立回源、双端分流、单台停用、故障源退出并回退旧通道，以及恢复后重新具备转发资格，共5组。
- 使用真实Nginx和本地HTTPS源核对Windows反代模板，覆盖TLS与Host、带空格路径、健康请求去掉认证/Cookie、普通请求保留认证/Cookie/查询/Range/压缩协商、Origin/Referer改写和Secure Cookie。
- PowerShell解析4份脚本、执行真实配置生成并拒绝无效端口；生成的FRP配置通过实际FRP程序校验。GitHub Windows运行器的原生ACL回归也已通过，覆盖空目录接管、仅SYSTEM/管理员权限、伪标记拒绝和受保护目录升级。
- 产品前端浏览器验收覆盖创建邀请、默认分享链接与折叠高级命令、设备搜索与状态筛选、无匹配结果、设备详情、停用确认及统计更新、撤销邀请，以及同事三步安装演示。另用正式页面和模拟接口确认刷新恢复、已使用邀请说明与下载禁用、无效链接不回退旧邀请。桌面与390px窄屏均无横向溢出，测试期间未发现页面错误或未处理异常。演示连接成功使用模拟数据，不代表真实电脑接入。
- 对公开发布副本替换实际部署地址与现场记录；源码及Release附件分别核对，不包含生产凭据或设备库。
- 上一预览版GitHub Actions的Linux测试和Windows PowerShell5.1检查已通过；本版发布时重新运行。自动检查不替代真实安装、SYSTEM网络与重启自启验收。

测试没有修改真实Jira。模拟测试中的地址和凭证为测试数据。
