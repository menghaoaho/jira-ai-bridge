## 1.2 安装体验改进

- 新增中文 Windows 安装窗口，显示五步进度；退出码0、2和失败分别展示连接成功、待检查和未完成。
- 新增 Agent 专属非交互指令，要求等待退出码和云端确认，使用与普通安装相同的授权和文件校验。
- 新增 `/relay/` 使用入口；只查看 Jira/工作台的用户无需安装，转发电脑通过专属邀请安装。
- 32项 Python 检查和15项前端用例已在本地通过。新增 Windows 原生窗口检查覆盖实际子进程、退出码0/2/1和窗口结果，待 GitHub Windows PowerShell5.1 运行器验证。
- 1.2正式页面配合本机模拟接口完成浏览器检查：拒绝其他站点邀请、正确打开同站邀请、复制 Agent 指令、下载专属CMD、未确认连接时不展示成功、邀请已使用后隐藏下载/Agent内容，以及复制不含授权的检查结果。390px使用入口无横向溢出；测试未连接真实设备。
