你可能会遇到的情况

我现在用的是 Mac 或手机

请把这个链接发送到需要安装的 Windows 公司电脑上，再打开。当前安装工具支持 Windows 10 / 11 的 Intel 或 AMD 64位电脑。

为什么还没有显示连接成功？

先确认已经双击下载的安装文件，并完成系统授权。公司网络无法访问 Jira 时，安装工具会给出提示。浏览器打不开 Jira、程序启动或页面显示等待，都不能代替连接成功确认。

安装被公司电脑策略阻止了

请联系管理员处理，不要关闭安全防护或修改公司策略。

邀请过期或被停用

请向管理员获取新的邀请链接。不要使用别人已经安装过的链接。
