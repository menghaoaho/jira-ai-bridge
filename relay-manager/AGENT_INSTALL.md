# 把安装交给 Agent

管理员在正式控制台创建邀请后，点击“复制指令，交给 Agent 安装”。同事也可以打开专属邀请链接，点击同名按钮，把整段内容粘贴给**当前 Windows 公司电脑上能够运行本机命令的 Agent**。

Agent 会获得与普通下载完全相同的单次授权，不需要服务器账号、Jira密码或开发环境。命令自动校验安装脚本和组件摘要，使用非交互安装模式；首次 Windows 系统授权仍需本人确认。

## 成功标准

- 退出码 `0`：安装完成，云端已确认这台电脑能够回源 Jira。
- 退出码 `2`：安装完成，连接尚未确认；保持公司网络，运行桌面“Jira转发-检查状态”。
- 其他退出码：安装没有完成。保留原邀请和本机进度，检查原因或联系管理员。

Agent 应等待整个命令结束后再判断结果，不能仅以窗口出现、程序启动或本地配置存在为成功。首次云端确认可能需要约两分钟，下载组件另需时间。

## 给管理员

指令由正式服务实时生成，包含这份邀请的专属授权与当前安装脚本摘要。不要把实际指令、链接或下载后的专属安装文件贴到公开GitHub仓库、Issue或群公告；私下发给对应同事即可。

只查看 Jira 的领导和同事无需安装：把正式服务的 `/relay/` 使用入口发给他们，点击“打开 Jira”或“打开工作台”，使用原有账号登录。

云端尚未部署时不要使用示例地址生成安装命令。公开仓库提供可定制源码与组件，不承载你的设备管理服务。
